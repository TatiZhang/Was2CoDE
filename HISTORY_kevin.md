### [2026-07-30] (Session 2 — TOST equivalence testing on DESeq2)
- Queried the wiki for TOST design guidance and implemented `R/deseq2_tost_helper_claude.R` + `tests/testthat/test_deseq2_tost_helper_claude.R`. 65 tests pass.
- **Key discovery: DESeq2 already implements TOST natively.** `DESeq2::results(dds, lfcThreshold = T, altHypothesis = "lessAbs")` computes exactly `max(p_lower, p_upper)` from two one-sided Wald tests (`R/results.R:533-539` in the DESeq2 source). It also refuses to run when `betaPrior = TRUE`, i.e. DESeq2 enforces the wiki's "no shrinkage" trap itself. The wiki's `[[analysis-tost-for-deg-equivalence]]` Route 1 does not mention this; the implementation is therefore mostly plumbing + partition logic, not new statistics. A unit test asserts bit-level agreement with DESeq2's `lessAbs` p-values and stat.
- **Decision: reimplement the TOST arithmetic in a standalone `tost_from_estimates()` rather than calling `results(..., altHypothesis="lessAbs")`.** Three reasons: (a) it is testable with no Bioconductor dependency; (b) the difference test and the equivalence test are then guaranteed to come from the *same* (lfc, se) pair, which `results()` called twice does not guarantee once filtering differs; (c) it generalizes to dreamlet/NEBULA/eSVD-DE unchanged, which is what Route 1's cross-method-agreement result needs.
- **New closed form worth keeping: the minimum rejectable bound is `Delta_min = |lfc| + z_alpha * se`.** TOST rejects at level alpha iff `lfc_threshold > |lfc| + z_alpha*se`, so the resource-based SESOI the wiki asks to report (`[[sesoi]]`, "smallest delta each cohort can reject") is available per gene with no search or simulation. Returned as `lfc_threshold_min`.
- **Decision: `independentFiltering = FALSE` when extracting lfc/se.** DESeq2's independent filter maximizes rejections of the *difference* null; reusing it would silently change which genes are eligible to be called stable. Replaced with an explicit, pre-specifiable `base_mean_min`.
- **Decision: `lfc_threshold` has no default.** A bound read off the data voids the type-I error guarantee (`[[sesoi]]`), so the API forces pre-specification.
- Cook's-distance-flagged genes are propagated to NA rather than kept: DESeq2 NAs the p-value but leaves lfc/se intact, so without the explicit flag an outlier-driven fit could be declared "stably expressed."
- Empirical finding (simulation): shrinking lfc by 50% raises the rejection rate at the equivalence boundary from ~0.05 to well above alpha — the anti-conservatism of `lfcShrink` in this setting is large, not marginal. Locked in as a regression test.
- **Non-obvious simulation trap, cost ~2 debug cycles.** A pseudobulk simulation with a large *one-directional* DE fraction breaks DESeq2's median-of-ratios size factors when the gene panel is small: with 20/60 genes 4x up in cases, size factors came out 0.90 (control) vs 1.12 (case), imposing a spurious -0.31 log2 shift on every null gene and turning 18/20 true nulls into "differential." Fix: make DE bidirectional and a minority of the panel. Worth remembering for any future benchmark simulation in the analysis repo, not just this test.
- Verified `use_t = TRUE` end-to-end: DESeq2 stores `tDegreesFreedom` in `mcols(dds)` and it comes out as residual df (12 donors - 2 coefficients = 10).
- Added `SummarizedExperiment` to `Suggests` (needed for `mcols()`; it is a DESeq2 dependency, so this is a formality).
- All roxygen blocks are `@noRd` so `devtools::document()` is a no-op for the new file — consistent with the other DE-method helpers being unexported. Revisit if Open Question 2 resolves toward exporting the wrappers.

### [2026-07-30] (Session 3 — factor pseudobulk construction out of the DE wrappers)
- Created `R/pseudobulk_claude.R` holding the four pseudobulk steps (`.check_donor_vars`, `.pseudobulk_from_seurat`, `.attach_donor_level_numerics`, `.prepare_pseudobulk_metadata`) plus `build_pseudobulk()`, which composes them and returns `list(mat, metadata, pseudo_seurat)`. Both `deseq2_helper()` and `deseq2_tost_helper()` now call it; `deseq2_helper.R` went from 84 to 31 lines and is now just "aggregate, build design, fit, extract."
- **Verified behavior-preserving, not assumed.** Snapshotted the pre-refactor `deseq2_helper()` from `git show HEAD:R/deseq2_helper.R`, ran both versions on the same simulated Seurat objects across four covariate configurations (none / categorical / numerical / both), and confirmed `all.equal()` on the full results tables. Kept the original's `eval(parse(text=...))` design construction in `deseq2_helper()` rather than switching it to `as.formula()`, so the diff is strictly a deletion.
- **Scope decision: only the *pseudobulk* stage is shared, not the fitting.** `.fit_deseq2_mle()` stays in the TOST file because it pins `betaPrior = FALSE` and `quiet = TRUE`, which would have changed `deseq2_helper()`'s console output and coupled the human's function to a TOST-specific choice. `deseq2_helper()` still calls plain `DESeq2::DESeq(dds)`.
- Added one genuine behavior change in `build_pseudobulk()`: a `stopifnot` that `colnames(mat) == rownames(metadata)`. Bulk fitters match countData columns to colData rows by position, so a mismatch would silently misassign donors instead of erroring. Currently unreachable (both come from the same `pseudo_seurat`), but cheap insurance if the pipeline is ever reordered.
- Test reorganization: the simulated-data generator moved to `tests/testthat/helper_simulate_pseudobulk_claude.R` (renamed `.simulate_donor_seurat`) so testthat auto-loads it for every test file. It now also emits `sex` (donor-constant categorical), `age` (donor-constant numerical), `n_umi` (deliberately cell-level, to test the donor-constancy rejection) and `true_lfc`. New `tests/testthat/test_pseudobulk_claude.R` (18 tests) and `tests/testthat/test_deseq2_helper.R` (3 tests) — the latter is the first coverage `deseq2_helper()` has ever had.
- Non-obvious behavior pinned by the new tests, worth knowing before touching `.prepare_pseudobulk_metadata()`: `id_var` is releveled but then **dropped** from the design; categorical levels are ordered by *decreasing frequency* (not alphabetically), which sets each factor's reference level; constant **factors** are dropped but constant **numerics** are not; and the returned column order is `categorical, numerical, case_control` — the case/control term must stay last because the coefficient name is built from it.
- Fixed a bad assertion I wrote: with 5 DE genes and alternating signs you get 3 up / 2 down, not a 50/50 split. Replaced the count check with a per-gene sign-agreement check against the generator's `true_lfc`, which is stronger anyway.
